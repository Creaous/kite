# API

Kite provides a REST API for integrations and other applications.

## Availability

Server administrators can choose to turn off the public API in the app settings. If this is the case, you will be unable to access the endpoints.

## How to use?

Kite uses [OpenAPI](https://swagger.io/specification/) to generate the API documentation. On deployed websites, you can find the OpenAPI spec at `[website]/openapi.json`.
